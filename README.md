
# 🔐 Python Password Complexity Checker

## About This Project
I created this beginner Python project to practise programming and explore cybersecurity concepts.

## Features
- Checks if a password has at least 8 characters.
- Checks if the password contains a number.
- Provides feedback based on these checks.

## Technologies Used
- Python 3
- Functions
- Conditional statements
- String methods

## How to Run
1. Install Python 3.
2. Download `password_check.py`.
3. Open a terminal in the file's folder.
4. Run `python password_check.py`.

## Example Output
For the sample password `Sec12345`:

    Testing password status:
    Strong: Password meets portfolio criteria!

## Limitations
This is a basic password complexity checker, not a complete security assessment. It does not check for compromised or easily guessed passwords.

## Future Improvements
- Allow users to enter their own passwords.
- Check uppercase and lowercase letters.
- Check special characters.
- Add more detailed password feedback.

This project helped me practise Python functions, conditional logic and string handling.
